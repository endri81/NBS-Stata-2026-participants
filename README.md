# NBS Seychelles · Stata training · 16–20 November 2026 · participant files

Exercises, catch-up files and handouts for the five days. The data are NBS's and are given out in the room; they are never put here.

## Getting the files
Each PC is set up before Day 1 with `setup/install_course.do` (see `setup/setup_guide.pdf`): it copies all five days into `C:\NBS_Stata`. To get a fresh copy at any time, click the green **Code** button, then **Download ZIP**.

## What is here
| Folder | Contents |
|---|---|
| `day1` … `day5` | Labs, practice set, daily check, catch-up files, laid out as `C:\NBS_Stata\dayN` |
| `handouts` | Slides, workbook, cheat sheet and readings for each day; `bibliography.pdf` |
| `setup` | `install_course.do`, `setup_check.do`, `setup_guide.pdf` |

Materials prepared for the National Bureau of Statistics, Seychelles, which may adapt and re-deliver them.
